# Spectral (bundled for PDF export)

Production Type **Spectral** static TTFs used by `../md2pdf_asc.py` and `../pdf_styles.css` for body / headings.

**These files are part of the asc-dev-stack git repo** (not downloaded at runtime). After `git clone`, PDF export works without installing system fonts.

| File | Role |
|------|------|
| `Spectral-Regular.ttf` | Body |
| `Spectral-Bold.ttf` | Headings / strong |
| `Spectral-Italic.ttf` | Emphasis |
| `Spectral-BoldItalic.ttf` | Bold italic |
| `OFL.txt` | SIL Open Font License 1.1 |

Extra weight files in this folder (Light, Medium, …) are unused by the PDF pipeline.

License: [OFL.txt](OFL.txt). Upstream: [google/fonts ofl/spectral](https://github.com/google/fonts/tree/main/ofl/spectral) / [productiontype/spectral](https://github.com/productiontype/spectral).
