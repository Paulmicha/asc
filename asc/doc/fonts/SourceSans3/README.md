# Source Sans 3 (bundled for PDF export)

Adobe **Source Sans 3** static TTFs used by `../md2pdf_asc.py` and `../pdf_styles.css`.

**These files are part of the asc-dev-stack git repo** (not downloaded at runtime). After `git clone`, PDF export works without installing system fonts.

| File | Role |
|------|------|
| `SourceSans3-Regular.ttf` | Body |
| `SourceSans3-Bold.ttf` | Headings / strong |
| `SourceSans3-Italic.ttf` | Emphasis |
| `SourceSans3-BoldItalic.ttf` | Bold italic |
| `OFL.txt` | SIL Open Font License 1.1 |
